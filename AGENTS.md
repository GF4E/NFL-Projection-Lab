# Contributor instructions

- Treat the repository as a public, educational NFL analytics engine.
- Never commit credentials, production bindings, personal configuration,
  database contents, provider payloads, or trademarked logo assets.
- Keep every forecast and training row leakage-safe and timestamped.
- Require rolling-origin validation, calibration evidence, and an ablation for
  model changes.
- Do not train on user decisions, displayed opportunities, win rate, or ROI.
- Preserve the public/private boundary documented in
  `docs/PUBLIC_PRIVATE_BOUNDARY.md`.
- The project is for education and analysis; model output is uncertain and is
  not an instruction to wager.
