# In-season learning loop v1 — registered 2026-09-13

User-authorized prospective protocol. Historical v1/v2/v3 harvest records remain unchanged.

- Operational weekly lineage starts from the deployed projection-v3 fit (calibration-only correction, mandatory adjusted PPD/pace baseline), not a restoration of the original v1 model. Weekly releases are `projection-v1.w<N>` with a separate full fit SHA256 and parent lineage. N is the upcoming NFL week. Same selected inputs, decay, ridge penalty, feature definitions and frozen residual distributions. Means/scales/intercept/coefficient estimates are fitting parameters. Any settings/input change uses the improvement gate and a new v2 lineage.
- Tuesday 06:00 America/Los_Angeles, DST-aware. Grade prior week first. Fail closed and retry if any scheduled prior-week game lacks a final or required PBP. Never backdate issuance. Receipt per season/week makes retries idempotent. No historical lock or first grade may be rewritten.
- Signed error = actual minus projected. Sigma = sample standard deviation, null with fewer than two observations. Team MAE pools both teams equally. Coverage is the original issued margin/total intervals; team intervals were not issued and are not invented. Separate AS_ISSUED and RETROSPECTIVE populations throughout.
- Reference is the existing adaptive 2016–2025 OOF experiment, game-weighted; coverage uses strictly prior-season residual shapes (2016 unavailable). It is historical development evidence, not an untouched holdout. Favorites are determined by projected score margin, ties separate. Absolute margin bands [0,3), [3,7), [7,14), [14,infinity).
- Input bands: roll/luck below -0.5, [-0.5,0.5), >=0.5; rest <6, [6,8), [8,14), >=14 days; wind <10, [10,20), >=20 mph; Elo gap <-100, [-100,0), [0,100), >=100; divisional/dome true/false; missing explicitly separate. Dome includes dome/closed roof. Buckets use team-score residuals, SE = sample SD/sqrt(n); flag iff n>=2 and abs(mean)>2*SE. These exploratory flags are not multiplicity-adjusted significance claims. A streak requires the latest three consecutive numbered NFL weeks with nonzero same-sign team errors; bye breaks streak.
- Store every edit revision with server timestamp, issuing version and projection seen at submission. Existing entries without a stored projection are excluded from paired learning, not reconstructed. All revisions retained; weekly learning uses the last eligible pre-lock revision per game, one observation per game per tag. Exclude server post_lock=true and entered_at>=cutoff, and retrospective projections. Direction is assessed separately for home score, away score, margin and total, including unchanged corrections in the denominator. Normalize tags with trim/lowercase; >=20 unique games and >=70% same-direction corrections raises a candidate, not an automatic finding of causality.
- At most one change is tested per completed week. Candidate is selected deterministically from supported edit flags first, then diagnostic flags, mapped to a measured model input group. One group addition/removal is the bounded automatic candidate vocabulary; unresolved/unmapped evidence is logged as deferred. Each candidate uses annual expanding-window OOF 2016–2025 with current fixed settings; compare identical games, and evaluate both methods on stored current-season as-issued feature snapshots. Candidate current-season scores are retrospective counterfactuals, never replacements for issued grades. Promotion requires >=1% paired OOF team MAE improvement and all four margin/total 50/80 coverage rates within 3 percentage points of nominal, with missing coverage failing closed. Log proposal and decision with before/after tables. No candidate without evidence; no forced weekly model change.
- Trajectories show six latest available pregame weekly snapshots of adjusted offense PPD, adjusted defense PPD allowed and roll index. Missing observations remain missing. Frozen cards retain their original issued payload; trajectory metadata may be attached in the display envelope and identifies reconstruction when an original snapshot was not captured.

Coverage comparison clarification before any proposal test: both OOF methods use the same original adaptive OOF residual shapes from strictly earlier seasons, matching the frozen distribution policy. A candidate changes one input group, not the interval calibration procedure. 2016 contributes MAE but has no valid OOF coverage.
