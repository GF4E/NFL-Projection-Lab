# Updated NFL Prediction Engine goal

Updated September 5, 2026. This written goal and the planning records are current. The in-app objective text remains unchanged because the available goal controls only change status; the goal remains active.

## Goal

Build and independently validate a useful **enhanced Elo NFL prediction engine**, keeping chronological observed-versus-expected team-strength updates at its core and translating them into coherent joint team-score forecasts. Improve the build process through measured experiments: **test → learn → retain, build, reconstruct, simplify or remove**. Develop graph engineering where it improves dependency analysis, testing efficiency or predictive value. Continue through authorized research toward an independently tested tool ready for owner page feedback.

Establish **at least 5% relative reduction in mean joint energy score against every admitted named external comparator, including the strongest**, on identical games and matched forecast origins:

`gain = 1 − mean(our energy score) / mean(comparator energy score)`

Require simultaneous 95% paired lower confidence bounds above 5%, registered calibration and diagnostic gates, and independent prospective confirmation. Freeze comparator eligibility, coverage, timing, inference and power rules before evaluation. No external archive is admitted, so this comparison is not yet testable and the target remains unmet. Frozen 1% historical research gates remain interim milestones.

## How the OS learns efficiently

For each substantive change, state a falsifiable hypothesis, the cheapest meaningful test and a bounded cost. Use focused regressions while building, real integration at the relevant boundary before expensive runs, and preregistered chronological backtests after eligible model or data revisions. Record what testing taught us and what we retain, improve, reconstruct or remove.

Measure total time, memory, expensive calls, preparation, validation and maintenance effort. Reuse valid evidence for unchanged dependencies while retaining mandatory coverage. Engineering optimizations must preserve scientific outputs. Current planning documents now link to one execution brief instead of duplicating the full status narrative.

Start graph work with existing source → forecast → score dependencies to expose missing evidence, affected tests, duplicated work and bottlenecks. Time-index team states so later outcomes cannot leak into earlier forecasts. Ordinary data structures come first; [NetworkX's graph algorithms](https://networkx.org/documentation/stable/reference/algorithms/dag.html) are an option when a measured need justifies them. Predictive graph features must earn inclusion through separate chronological tests and ablations; no new framework is a prerequisite.

Preserve issued predictions. Tuning against an already observed week and rescoring it cannot create a valid out-of-sample result. Eligible outcomes may update ratings under frozen rules; structural changes require newly preregistered experiments. Short rolling Brier scores are descriptive diagnostics, not automatic retuning or acceptance gates.
