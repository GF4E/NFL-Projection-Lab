## Operational definitions

- QB identity: the player with most qb_dropback==1 plays in the team's immediately previous completed game, including scrambles (rusher ID for scramble; passer ID otherwise), excluding no-plays. Identity counts use full games, not the garbage-time filter. Ties: lexicographically smallest stable player ID. No prior team game => unknown unless an eligible depth chart explicitly supplies the starter. Missing IDs/counts stay unknown. Never use target-game participation or target-game schedule QB IDs as pregame information.
- From 2009 use the authorized pregame proxy, overridden by an explicit different starter in that week's nflverse depth chart or injury record. Weekly historical charts identify QB depth rank 1; ambiguous multiple rank-1 IDs do not override. From 2025, latest source timestamp before T75 in the preceding seven days. Historical week reports without timestamps are WEEKLY_PROXY_ISSUANCE_UNVERIFIED; never claim exact issuance. Reports downloaded now do not prove original publication. Current reports must have actual receipt before T75. Injury status alone does not name a replacement; only an explicit starter ID can override. Conflicting explicit reports at equal precedence => unknown override, keep flagged fallback. Before 2009 previous-game-only rule, flagged. Record row source hashes, selected identity, effective date/week, cutoff, fallback and missing override evidence.
- QB EPA/dropback and available-play CPOE: only earlier games by selected player, prior/current season blend and optional 8-week decay matching v2 features, weighted by observed play counts within each season. Exclude Q4 plays with WP outside [0.05,0.95], kneels/spikes and no-plays for performance. CPOE unavailable => null, never zero. Career starts: count earlier actual starts reconstructed from first non-null offensive QB dropback identity in each game; labeled CAREER_START_PROXY, not official starts. Career counters include postseason, never target-game outcomes. Backup flag: selected QB differs from latest eligible explicit first-string chart QB; no qualifying chart => unknown, not false. First known start/attempt with complete 1999-forward history can be zero; left-censored careers explicitly flagged.
- PRESSURE_PROXY generated/allowed = sum(qb_hit)+sum(sack) divided by qb_dropback count, on qualifying normal dropbacks after garbage-time exclusion. Literal requested sum, even where source flags overlap; report overlap. Generated is prior defensive games, allowed prior offensive games, same history weighting as v2. No direct-pressure equivalence claim. Missing hit/sack field values => unavailable counts, not zero observations. Retain data coverage flags for 1999 onward.
- Pregame kicker: latest eligible explicit K/PK depth rank 1; else most FG attempts (then XP attempts, then stable ID) in immediately previous team game. No target-game identity. Career FG by short <=39, medium 40-49, long >=50: all earlier valid made/missed/blocked attempts for that selected player across teams, including postseason and garbage time. No-attempt band => null. History starts 1999; flag left censoring for players present at boundary. Source inspection must explain original gap. Names are metadata; IDs govern joins.
- All performance history updates occur after entire week's features; prior team-game identity can use only games completed before target kickoff/cutoff. No future season labels enter fitting, selection or intervals. Keep frozen v2 football baseline and population unchanged for paired comparison.

### Definition clarification before comparative results

The initial backup rule (different from the same chart that selects the QB) would mechanically produce false for every chart override. Replace it with BACKUP_PROXY: selected QB differs from the team's incumbent, defined as the QB with the most earlier first-dropback starts in the current season, or previous season if no current starts. Ties use stable ID. Missing incumbent => unknown. This measures replacement of the historical incumbent, not an official depth rank or injury diagnosis. Retain both selected ID and incumbent ID per row. Explicit charts remain authoritative for selection. Career start counts are left-censored and unavailable for players observed at the 1999 boundary; career FG bands likewise remain unavailable for boundary kickers, rather than presenting partial careers as complete.
