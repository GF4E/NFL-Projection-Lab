Infrastructure lane only: no model, score, interval, explanation or layout change. Retain exact upstream JSON text through download, cache and HTTP response. Use row 2 of the existing publication cache as the explicitly new raw-text format; row 1 remains untouched for rollback and legacy UI fallback. This avoids a database migration and prevents an old reserialized payload from being labeled original bytes. Tier 1 convention: separate format key using the existing integer primary key. No fitted parameters or gates.

Raw endpoint must return 503 if only a legacy cache is available and the source cannot be reached. UI readers may retain the existing validated last-good legacy display. Keep frozen-record/monotonic guards, no-follow redirects and failed-cache-write behavior. Test raw numbers including trailing .0 and exponents, warm cache, stale fallback, legacy migration, failed writes, changed frozen games and route response bytes. Then run the real Worker runtime against published source and verify deployed exact hashes from the droplet. Preserve site audience and build-output-only mirror policy.

Measured source is 6,566,184 bytes, above D1's 2,000,000-byte row limit (https://developers.cloudflare.com/d1/platform/limits/). Store lossless gzip/base64 with original-byte SHA-256 and length in row 2, bounded below 1.9 MB; decompression is capped at 8 MiB. The actual Worker/D1 test retains it at 720,672 bytes and restores exact text. The initial integration test failed because its legacy fixture attempted an oversized uncompressed D1 row; use a valid small legacy board to test migration while preserving that failure log. Raw source and original cache row remain unchanged. Cache timestamps are captured before fetching so slower earlier requests cannot overwrite later commits. Snapshot tests use their original Europe/Berlin timezone; no snapshots changed.
