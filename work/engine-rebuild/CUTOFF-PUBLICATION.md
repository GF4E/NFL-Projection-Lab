# Actual cutoff publisher integration

Infrastructure capability, not an activated method or control migration. The actual preparer, publisher, immutable bundle, first-lock, first-grade and board-evidence consumers now share the recorded cutoff contract when the prepared manifest explicitly selects it. The scheduled production caller still uses the legacy preparation path. An explicit cutoff preparation cannot silently revert to that path.

## What is bound

Each new card pins its common preparation/calculation, final-eligible or provisional role, original fit/calibration, exact input DTO, schedule identity, source reconstruction, outputs, contributions and WHY. The immutable bundle has a separate durable predeadline issuance receipt. Completing a score calculation before T75 does not authorize a bundle first committed at or after T75. First lock rechecks the calculation from retained sources. Provisional cards become MISSED; incomplete contracts fail closed. A cutoff card cannot strip bundle references and pass as an unbundled legacy record. The grader requires a locked cutoff card and preserves the first grade when a later final differs.

Old locked/retrospective records retain their original field sets. No point method, fit, calibration, uncertainty family, statistical gate or website layout changes. Shared edits remain separate from the protected model outputs. Source dependencies for the new path are included in the scheduler's existing commit allowlist.

## Remaining acceptance

The automatic state selector and production activation remain absent. Once cutoff mode is selected, future preparations must receive explicit qualified state references; default legacy preparation refuses that manifest. Partial-slate mapping cannot omit an eligible forecast. Compatible full-pipeline rollback, durable capacity, actual scheduled/live/public verification, current-lineage Season references, warmup and registered statistical migration remain open. Board references in this canary still use the retained SUPERSEDED adaptive series, explicitly; they do not qualify current references.

Provider requests: 0. New spending: 0. Qualified Linux root free bytes: 151,490,560; this check does not resolve the capacity dependency. Canary output-byte totals include copied retained sources and are not estimates of incremental daily production growth.

Least certain: full live-consumer and scheduler compatibility beyond the captured slate; this is why the explicit adapter is tested without activation.

Confidence: medium—the bounded contract claim holds on captured authoritative source/fit inputs, but depends on simulated timing/finals rather than a completed live cycle. Medium means the evidence holds on authoritative data but depends on a choice that could reasonably differ. Lower to low if independent reconstruction or a live consumer contradicts the preserved identities or cutoff behavior. Improved predictive accuracy is not claimed.
