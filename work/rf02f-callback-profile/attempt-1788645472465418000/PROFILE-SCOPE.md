# Bounded synthetic callback profile

The prior goal turn made progress: it independently closed RF-02F's actual cost rejection. The frozen run and all 66 source/test files remain unchanged. This profile does not restart it or estimate predictive quality.

Question: can empirical-atom insertion account for enough complete fitting/scoring time to plausibly achieve the required 52.47% reduction in their combined maxima, holding other frozen cost terms fixed? Measure inclusive grid construction and ordinary function costs too, so a failed insertion hypothesis can inform the next decision without an unplanned experiment.

Bound one command, including imports/setup, at 60 seconds / 2,048 MiB. Use the accepted tiny forecast fixture's real enhanced-Elo states and complete assembler resolution callback, with explicitly synthetic mapper supports. Current actual maximum-callback metadata has 685/693 atoms and primary 64×64 grids, whereas the original tiny fixture has three atoms. A three-atom profile alone cannot answer the question.

Fix two supports before measurement: a three-atom control spanning 0–62 and a 700-atom synthetic stress case formed from 350 deterministic off-diagonal coordinate pairs in 0–62 and their transposes. Weight the stress pairs with a fixed Gaussian-shaped weight centered at (22,22); no historical score values or fitted parameters enter the synthetic fixture. Report actual resulting support and grid dimensions rather than assume they match history. Reuse the fixture's real native forecasts for off-diagonal full and independent-marginals variants, and the two zero-update outer controls. All score calls use double_grid=True and diagnostics=True.

Measure the actual `_Assembly.resolve` fitting/validation/descriptor/recovery callback and complete unchanged scorer. Temporary in-memory instrumentation wraps grid construction and moves the exact original atom loop into a timed helper, including its cast. No source file is patched. Count inclusive grid time separately from its deposition subset; never add them together. No per-atom timer. Alternate eight paired unchanged/instrumented executions per case after one warmup pair; compare every descriptor, grid byte hash and canonical metric byte hash. Report instrumentation overhead and raw per-pair timings. An additional cProfile pass on unchanged code locates other callback work; its timings are diagnostic and not substituted for unprofiled costs.

Report deposition time divided by paired unchanged complete callback time as an optimistic removal ceiling, along with the instrumented fraction and overhead. This is not a claimed speedup or a confidence bound for historical maxima. If even this optimistic measured ceiling is below 52.47% across the larger-support cases, stop the insertion-only hypothesis without implementing it. A larger or noisy fraction only warrants further investigation, not a historical run.

The source has no interpolation: integer atoms add directly to grid cells. Authenticated `from_scores` mappers deduplicate integer pairs, but directly constructed distribution objects can retain duplicates or fractional coordinates that collide after casting. Any future implementation must preserve duplicate accumulation, ordering, casts, zip truncation, failures, background/tail addition, normalization and independence behavior. Profiling does not qualify a fast path.

Persist this scope, script, exact source map, every attempted process report/log, timings and output equality evidence. Stop on the first unexpected numerical or equality failure. No fixture bootstrap, historical archive admission, provider access, production or publication.

Pre-execution implementation detail: the unchanged warmup captures actual returned grid references for hashing after callback timers. Measured unchanged calls have no grid wrapper and compare their descriptors and metric bytes to that reference. Every instrumented call compares its actual grids to the unchanged warmup grids. Thus baseline grid equality is established through the captured warmup and identical fitted descriptors/metrics, not by claiming that grids were intercepted in the unwrapped measured baseline. cProfile activates only inside the complete accounting callbacks; it excludes subsequent equality hashing and JSON persistence. The assembly constructor and historical archive admission are explicitly outside this synthetic callback profile.
