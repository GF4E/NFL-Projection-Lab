The mathematical issue is substantive: win probability, a predicted score pair, or separate spread/total summaries do not determine the joint distribution of final home and away scores. An invented Poisson/normal/copula adapter or a point-mass representation would define another model. It would not measure the native alternative against the frozen target. The >=5% question therefore remains untested, regardless of these publishers' side-pick, win-probability or commercial performance claims.

Smallest concrete admission step: before requesting any data or activating access, obtain a **documentation-only capability and rights answer for one live publisher** confirming that native pregame joint final-score PMFs or paired home/away simulation draws exist. PFF is a possible inquiry candidate because it publicly documents simulations; that does not establish game-level joint output. The exact unsent question can be:

“Do you make available native NFL final home/away score joint probabilities or paired simulation draws, including overtime, for historical regular-season games as originally issued? If so, please provide only a schema/example description and documentation of forecast issuance time in UTC, the contemporaneous model version and information cutoff, archive revision policy, season coverage, and permitted local research/derived educational-site use. We require versions issued no later than Tuesday 07:30 America/Los_Angeles for that week; game date or a postgame backfill is insufficient. No API, account, download, trial or purchase should be activated.”

Sending that inquiry needs explicit owner authorization. A positive answer would still precede a separately bounded, approved sample acquisition and independent admission check. A negative answer or absent joint output leaves the candidate ineligible; it does not authorize an adapter or a weaker target. FiveThirtyEight remains the clearest documented public rights starting point only if a separately preregistered secondary win-probability comparison is later useful.

The active goal also permits an explicitly preregistered, named model-plus-adapter comparator. Such an adapter must have an identified target, input timing, data rights, training-only estimation, calibration and fair common-game evaluation. That route is distinct from comparing native joint distributions, and this documentation screen does not admit or select an adapter. Native-output absence is not proof that every transparently adapted comparison is impossible.
